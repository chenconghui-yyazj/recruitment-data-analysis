# Data Cleaning Documentation (English)

> Corresponds to competition **Task 1: Data Cleaning & Governance**. This document describes the full process from raw recruitment data to an analyzable dataset. See `code/data_cleaning.py`.

## 1. Data Overview

- **Data source**: Listed-company recruitment data (2014–2026), including job category, education requirement, salary level, work location, industry distribution, publish time, etc.
- **Processing strategy**: The raw data is large, so we use **chunked reading + 5% random sampling** (`random_state=42` for reproducibility) to reduce memory usage.
- **Final dataset**: `data/recruitment_data_cleaned.csv` — **323,818** records, **10** standardized fields.

## 2. Field Standardization

To avoid ambiguous naming and ease analysis, a unified field mapping is defined:

| Dimension | Raw field (optional) | Standardized field |
| --- | --- | --- |
| Time | Publish date / End date | `发布时间` (publish time) |
| Industry | Listed-company industry | `上市公司行业` |
| Region | Work city | `工作城市` |
| Education | Education requirement | `学历要求` |
| Job | Primary category / Job title | `岗位分类` |
| Salary | Min salary / Max salary | `最低月薪_数值` / `最高月薪_数值` |

Fields with more complete information are preferred; synonymous fields are deduplicated.

## 3. Salary Conversion & Outlier Handling

1. **Numeric conversion** `convert_salary`:
   - Handles thousand-separator commas, full-width commas, "元" suffix, "k" (thousands) formats;
   - Keeps only values in the valid range `1000 ≤ monthly salary ≤ 500000`; out-of-range values are treated as invalid.

2. **Validity filter**: removes records with min salary ≤ 0, max salary ≤ 0, or max salary < min salary (contradictions).

3. **IQR outlier detection** (based on max salary):
   - Compute quartiles `Q1`, `Q3`, `IQR = Q3 - Q1`;
   - Normal range `[Q1 - 1.5·IQR, Q3 + 1.5·IQR]`; records outside are identified as salary outliers and removed.

## 4. Missing-Value Handling

- Drop records missing key fields (**education / industry / city**) to keep analysis dimensions complete;
- Compute derived field `平均月薪 = (最低月薪 + 最高月薪) / 2`.

## 5. Duplicate Handling

- Use `drop_duplicates()` to remove exact duplicate records, preventing the same job from being counted multiple times.

## 6. Time Field Processing

- Parse publish time as `datetime`, extract `年份` (year), `月份` (month), `年月` (year-month);
- Filter to the valid year range (2014–2026) for consistent time-series semantics.

## 7. Education Simplification

Education requirements are grouped into five categories:

| Raw expression | Simplified result |
| --- | --- |
| 博士 (PhD) | PhD |
| 硕士 (Master) | Master |
| 本科 (Bachelor) | Bachelor |
| 大专 (Associate) | Associate |
| 不限 / 无 / 不限制 (Open) | Open |
| Others | Other |

## 8. Governance Result

| Step | Description |
| --- | --- |
| Salary | Numeric conversion + range validation + IQR outlier removal |
| Missing | Drop records missing key fields |
| Duplicate | Remove exact duplicates |
| Time | datetime parsing + year filtering |
| Education | Five-category simplification |
| Output | 323,818 records × 10 standardized fields |

The governed data is ready for demand-feature analysis and trend forecasting; the process is fully reproducible (fixed `random_state`).
